# PM Admin Dashboard
PM Admin Dashboard adalah aplikasi web frontend yang dibuat sebagai bagian dari technical assessment.

## 🚀 How to Run the Application Locally
pnpm install
pnpm dev

## 📦 Installation Steps
1. git clone
2. cd project
3. pnpm install

## 🌐 Live Demo
The application is deployed and available at:
https://pm-admin-two.vercel.app/

## 🛠 Tech Stack Used
- React
- Vite
- JavaScript + SWC
- React Flow
- Zustand
- HeroUI
- Tailwind CSS
